# ⛏️ Deep Digger

**Dig Deeper. Discover More. Upgrade Your Adventure.**

A 2D mining and progression game developed by **STN Games** using Unity.

Deep Digger is a mobile mining game where players explore underground layers, collect valuable minerals, upgrade their equipment, and discover increasingly rare resources.

Developed as part of the **STN Games — Play Beyond.** game portfolio.

---

## 🎮 About the Game

In Deep Digger, players start their mining journey with basic equipment and gradually work their way deeper underground.

Every mining expedition provides opportunities to discover valuable ores, earn coins, and improve mining efficiency.

The objective is simple: **Mine, Collect, Upgrade, Repeat!**

## ✨ Game Features

### ⛏️ Mining System
- Interactive 6×6 mining grid.
- Hold-to-mine gameplay mechanics.
- Different mining speeds depending on pickaxe upgrades.
- Underground progression with increasing depth.
- Persistent broken blocks during mining sessions.
- Dynamic generation of new underground layers.

### 💎 Minerals & Resources
Discover and collect 10 different resources:

| Mineral | Base Value |
|---|---:|
| Stone | 1 |
| Coal | 3 |
| Copper | 7 |
| Iron | 15 |
| Silver | 30 |
| Gold | 60 |
| Crystal | 120 |
| Diamond | 250 |
| Emerald | 500 |
| Sapphire | 700 |

### ⚡ Energy System
- Energy-based mining mechanics.
- Maximum starting energy: 100.
- Energy consumption during mining.
- Automatic energy regeneration.
- Surface return and resting mechanics.

### 🎒 Inventory System
- Limited initial backpack capacity.
- Collect and store mined resources.
- Sell collected minerals to earn coins.
- Upgrade backpack capacity to continue mining longer.

### 🔨 Upgrade System
Improve mining performance through upgrades:

- **Pickaxe:** Increase mining efficiency.
- **Backpack:** Expand inventory capacity.
- **Energy:** Improve maximum energy capacity.

### 🏪 Shop & Economy
- Sell minerals for in-game currency.
- Purchase equipment upgrades.
- Gold and premium diamond currency systems.

### 🏆 Collection System
- Discover different mineral types.
- Track collected and missing resources.
- Complete mineral collections.

### 🌍 Localization
Language support planned or implemented using Unity Localization:

- 🇬🇧 English
- 🇹🇷 Turkish

## 🚀 Getting Started

1. Clone or download the repository.
2. Install Unity Hub.
3. Install a compatible Unity 6.3 LTS editor.
4. Open the project using Unity Hub.
5. Allow Unity to import the project assets and dependencies.
6. Open the main game scene and enter Play Mode.
